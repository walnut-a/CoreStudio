# 来源层说明

CoreStudio Wiki 不把所有内容复制一遍。来源层由两部分组成：

1. 仓库当前代码、测试、配置、文档、规格、计划和 Git 历史；
2. 人工放入 [`../raw/`](../raw/README.md) 的不可变外部快照。

[`source-map.md`](source-map.md) 记录重要来源分别能证明什么、不能证明什么。来源摘要只帮助路由，不能替代阅读原文。

## 来源类型

- **implementation**：代码、测试、package scripts 和运行配置；用于确认当前行为。
- **contract**：明确标为当前事实来源的接口或架构文档。
- **stable-doc**：仓库说明、产品原则、设计系统和维护文档。
- **spec / plan**：已确认需求、目标状态、实现记录；必须结合状态判断是否已经落地。
- **history**：旧计划、审计、发布记录和 Git 历史；用于解释演进，不自动代表当前状态。
- **external**：仓库外方法、研究和参考资料；不能覆盖项目自身事实。
