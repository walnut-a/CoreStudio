# CoreStudio 查看模式

## 已确认的边界

同一批项目图片提供画布和查看两种展示方式。查看模式自动平铺、点击放大、关闭回到原网格位置，不能拖动布局或批注。图片集合取当前画布未删除的图片文件；同一原图的多个画布实例只展示一次，保留但已从画布删除的资产不展示。异常缺图使用占位和已有项目维护能力，不创建第二套图片库。

仅修改 CoreStudio 客户端封装层，不改 Excalidraw 基座、项目格式或画布坐标。无设置开关，无排序、筛选、重命名、删除或独立文件管理入口。

## 交互与实现

- 默认画布。入口位于“图片资产”面板标题栏右侧，使用网格图标与“网格查看”提示，不在画布常驻模式切换按钮。进入网格收起资产面板；网格左上角提供“返回画布”，返回后焦点回到图片资产按钮。模式不写入项目数据。
- 网格使用同一行等高、宽度随原图比例变化的排列，完整显示缩略图；页面使用很淡的中性底色，图片不额外铺底。默认不显示图片名，悬停提供完整名称提示，屏幕阅读器和大图详情保留名称。按画布图片顺序展示，新加入的图片自然出现。
- 点击图片打开大图，提供适应窗口 / 原始尺寸、上一张 / 下一张；Escape 或关闭按钮返回原网格滚动位置和焦点。
- 大图右上角提供“在画布中定位”：退出查看模式，在画布中居中并选中当前图片。该显式动作会调整视口与选区；普通返回继续恢复原状态。同一文件有多个画布实例时定位第一个未删除实例，项目切换会取消待执行定位，图片已不存在则不跳转到其他图片。
- 网格虚拟化，只加载可见范围缩略图；大图按需读取原图，切换图片或项目后丢弃过期异步结果。
- 画布保持挂载和原尺寸，以保留布局、视口、选择、撤销历史及后台 Room 同步；查看时隐藏且 inert，隐藏编辑侧栏和生成输入框，阻止键盘、剪贴板、拖入和桌面编辑菜单触发画布修改。
- 使用基座既有 `interaction={false}` 关闭用户输入。该参数会清空选区，因此客户端临时保存进入查看前的选区，退出后仅恢复仍存在的元素；跨项目不恢复。生成框保持挂载并隐藏，保留草稿与内部编辑状态。
- 外部自动接纳、Agent 写入、既有生成任务继续同步。图片删除时从网格移除，正在查看的图片被删除则关闭详情。
- 使用既有设计 token 与中英文文案；空项目显示安静的空状态，读取失败可重试。

### 推荐先做的精修

1. **网格图片的承托更轻。** 当前图片区固定 176px 高、使用 `--color-surface-low` 实底，非同宽高比图片会露出灰紫色底。建议降低底色存在感，继续完整比例显示；白底图靠极轻的边界保持辨识。维持现有圆角和 16px 基础间距，不加卡片阴影。先保留当前密度，使用横图、竖图、白底产品图、透明图、长图的混合样本判断是否需要放大图片区，避免仅凭彩色测试图调整。
2. **文字层级与对齐。** 名称保留一行，沿用 12–13px 级别与可读的次级文字颜色；图片、名称、顶栏使用一致的左边线。完整名称在悬停／键盘聚焦时可查看。尺寸信息留在大图详情，不为每张缩略图叠加元数据。
3. **形成完整但安静的浏览顶栏。** 目前返回按钮绝对定位覆盖滚动区，网格靠顶部 padding 留空。建议让“返回画布”进入紧凑、固定的顶栏，图片从其下方滚动，避免图片滑到按钮后面；沿用同色表面，不加入大标题、筛选器或额外模式切换。标题栏与网格统一边距。
4. **大图控件更集中。** 当前详情同时有顶部标题／原始尺寸／关闭和底部上一张／页码／下一张。建议将名称与尺寸靠左，适应窗口／原始尺寸和关闭靠右；上一张／下一张使用同尺寸箭头图标，页码作为轻量文字。保持固定位置和可发现性，不把关闭按钮完全自动隐藏。使用现有按钮、图标线宽和主题 token，避免发展成另一套查看器皮肤。
5. **消除生硬的打开与加载。** 已有缩略图可作为原图就绪前的过渡图，原图加载完成后自然替换；建议短暂淡入／轻微缩放，约 160–200ms 作为试验起点，响应减少动态效果偏好。关闭仍返回原网格位置和焦点。第一轮不引入动画依赖或复杂的跨节点共享元素系统；只有简单过渡的实机结果不足时再评估。

### 顺序与完成标准

- 先做网格底色／文字／对齐和顶栏，再做详情控件与加载衔接；先更新可检查的设计预览，再进入生产组件实现。
- 保留图片资产标题栏入口、同画布图片集合、只读交互、视口／选择／撤销／草稿状态和后台同步。
- 改动应集中在客户端 `ImageBrowseView` 及样式、少量 App 布局接线；无基座修改、新依赖、项目格式或用户设置。
- 使用真实类别混合图片验证浅／深色与正常／最窄桌面窗口。检查白图边界、透明图、长文件名、原图延迟和失败、关闭后滚动位置及键盘焦点；源码 Electron 验收按固定 SOURCE DEV 入口执行。
- 不把增加瀑布流、缩略图尺寸滑杆、随机背景色、毛玻璃、大幅弹跳或卡片悬浮上移当作精致感的必要条件。
