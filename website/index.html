生图工具这么多，为什么 CoreStudio 仍然值得考虑？

生成一张图已经不是难事。真正影响工作体验的，是生成之后，图片留在哪里、如何继续工作，以及 Agent 能不能加入同一套流程。

大多数生图工具都运行在网页中，生成结果不会自动进入本地项目。后续整理与备份还要额外花时间。CoreStudio 将项目、素材和生成结果保存在你的设备上，随时可以查看、管理和备份。

CoreStudio 没有重新发明画布。Excalidraw 已经具备成熟、丰富的开源画布能力，能很好地服务创意与探索类工作。CoreStudio 只在这个基础上增加图片生成、本地素材和 Agent 协作所需的功能。

图片生成 API 的价格已经足够低。得益于 GPT Image 2 和 Nano Banana 2 的高性价比，在用量不极端时，个人充值 API 也很划算，还能自行选择模型、控制预算。

不想配置 API Key，也可以借助 Agent 生图。CoreStudio 提供完善的 CLI 支持，可以借助 Codex 等产品的生图能力，并把结果写回 CoreStudio。这条协作路径不由 CoreStudio 额外收费；第三方产品的订阅和额度仍按各自规则计算。
