# CoreStudio 工作区围栏历史说明

> 状态：已废止并移除
>
> 废止日期：2026-07-26

CoreStudio 曾在 Excalidraw 无限画布之上增加一套自有“工作区围栏”，包括动态虚线边界、缩放到工作区全貌时的软停顿，以及图片落位时对 `workspaceBounds` 的优先搜索。实际使用表明，这套机制既不是硬边界，也不是防止 Agent 图片散落的可靠保证：

- 远端元素会被下一次边界计算自动纳入；
- 围栏内没有空位时，放置逻辑仍会回退到围栏外；
- Agent writer 本身并不依赖围栏，稳定性主要来自批量布局、语义锚点和占用避让；
- 缺失 participant 视口时回退固定原点，才是已有项目出现远端落点的真实风险。

因此，CoreStudio 已删除围栏视觉、缩放门控、App 状态和图片布局中的边界参数，恢复纯粹的无限画布语义。图片局部性现在由以下规则保证：

1. 同一轮图片作为一个批次布局和写入。
2. 有参考元素时使用合并后的参考边界。
3. 无参考元素时使用当前 participant 视口；视口缺失且项目已有内容时，选择最接近场景中心的实际占用元素作为锚点，不回退固定原点，也不落在远距内容簇之间的空白中点。
4. 空位搜索从冲突位置按实际距离展开到障碍边缘，返回最近的整批合法位置；不受固定搜索半径或远端场景外边界影响，也不退回已知重叠点。
5. 通用场景边界、占用区域和视口换算集中在 `sceneGeometry.ts`，不再承载任何围栏语义。

- `docs/spec/2026-07-23-corestudio-agent-board-editing-soft-delete-and-incremental-writeback.md` 第 11.5–11.6 节；
- `docs/plan/2026-07-26-workspace-fence-removal.md`。
