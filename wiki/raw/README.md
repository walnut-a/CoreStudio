# 原始来源

本目录用于保存人工明确交付给 Wiki、且需要长期离线复核的不可变来源快照，例如访谈记录、外部文章 Markdown、会议纪要导出或数据快照。

## 规则

- 已摄取文件不可原地编辑；来源更新时新增带日期或版本的文件。
- 文件名使用 `YYYY-MM-DD-short-title.ext`，未知日期可省略日期但必须在来源说明中记录访问时间。
- 二进制大文件、凭据、用户项目数据、个人敏感数据和可从仓库稳定获取的构建产物不放入这里。
- 仓库已有代码和文档本身就是来源，不复制到本目录。
- 每个来源在 `../sources/` 中建立说明，记录出处、适用范围、可信度和已影响页面。

当前没有保存额外原始快照。Karpathy 提示以外链和本地来源说明记录，见 [Karpathy LLM Wiki 模式](../sources/karpathy-llm-wiki.md)。
