一次安装 Skill 与 CLI

不要下载 Skill 压缩包，也不要运行网络安装脚本。CoreStudio 使用已签名应用内自带的集成资源。

  1. 安装并打开 CoreStudio

    尚未安装时，从 GitHub 下载最新签名 macOS 版本。保持 CoreStudio 运行并开启 Agent Bridge；目标项目不需要预先打开桌面标签。

    下载最新版本

  2. 打开 Agent 集成设置

    在 CoreStudio 中打开“应用设置 → Agent 集成”。官网无法替你打开或检测这个本机页面。

  3. 安装 Codex

    点击安装、更新或修复。CoreStudio 会在同一个受管操作中准备宿主 Skill 和共享 CLI。

    ~/.codex/skills/corestudio/

  4. 新建 Agent 对话

    已经打开的对话可能不会重新扫描刚安装的 Skill。首次使用前请新建一个本地对话。

先验证安装，再验证项目连接

安装完整与项目可连接是两个不同层级。先检查版本，再检查正在运行的 CoreStudio。

1. 安装完整性

这个命令不要求当前已经打开项目，也不要求 Local Bridge 可达。

corestudio --version --json

2. 本地连接

打开 CoreStudio 后再运行。它只报告 Bridge 状态，不修改项目数据；认领 Board 后，项目命令使用任务 session 绑定。

corestudio read status --json

让一个 Agent 任务绑定一个项目

保持 CoreStudio 运行并开启 Agent Bridge。Skill 会建立任务 session，并在认领 Agent Board 时绑定所选项目；桌面标签不决定目标。

打开我选择的 CoreStudio 项目，把当前任务绑定到它的 Agent Board，读取画布与选区，并告诉我可以继续做什么。

Skill 会为 Codex 建立并复用仅随当前进程存活的 Agent session；认领 Board 后，此任务独立绑定该项目，不受桌面标签影响。

CLI 常用任务

这里提供按任务组织的入口，不复制完整命令合同。Agent 调用应保留 JSON 输出，完整参数以原始合同为准。

检查状态

corestudio read status --json

读取选区

corestudio read selection --agent-session <sessionRef> --json

打开 Agent Board

corestudio read board-url --json

写回图片

corestudio write image /absolute/path/result.png --source-type generated --origin agent-board --agent-session <sessionRef> --json Agent session

写回流程图

corestudio write diagram --format mermaid --file /absolute/path/process.mmd --anchor auto --agent-session <sessionRef> --json Agent session
